# Apple Pay + Adyen Checkout

A sample e-commerce checkout application integrating:

- Apple Pay directly for the customer experience
- Adyen for Apple Pay payment processing

## Project Milestones

1. Build merchant checkout UI
2. Integrate Apple Pay button and availability checks
3. Implement Apple Pay merchant validation
4. Integrate Adyen payment processing
5. Handle payment responses and webhooks
6. Test end-to-end checkout
